# GEMINI.md — короткие правила для Gemini-агента

Antigravity сам подставляет этот файл в каждый разговор, поэтому он короткий. Не делай его длинным.

1. **Твои задания — `FRIEND_TASKS.md`.** Читай там только «СТАТУС», «Часть 1», «Общие правила этапа 7» и раздел своего задания. Другие задания не читай.
2. **`CLAUDE.md` целиком не читай**: он огромный (~290 КБ). Нужны только три коротких раздела:
   - «Обязательные правила кода»;
   - «Решения владельца: этап 7»;
   - «ЭТАП 7».

   Остальное ищи поиском по слову или номеру решения и читай только найденный кусок.
3. **Экономь токены.**
   - Большие файлы кода читай кусками вокруг найденного места.
   - После своей правки файл не перечитывай.
   - Архивы (`*_archive_*`), `TEAM_PLAN.md` и `GEMINI_GUIDE.md` не открывай без нужды.
4. **Проверка перед push:** `sh scripts/check.sh`, затем `git pull --rebase`, затем `git push`.
5. **Старая большая инструкция** для друга — модели, Blender, имена и размеры моделей, задания 1–19 — теперь лежит в `GEMINI_GUIDE.md`. Если где-то написано «`GEMINI.md`, раздел …», этот раздел теперь в `GEMINI_GUIDE.md`. Открывай только нужный раздел.
