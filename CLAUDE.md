## Что за игра

Кооперативная игра на 1–4 игроков. Игроки — ночная охрана музея. Каждую ночь приходят воры и пытаются вынести экспонаты. Нужно поймать их до того, как они дойдут до выхода.

Главная идея — **асимметрия информации**: оператор видит всё через камеры, но не может ловить; патруль может ловить, но не видит, где воры. Без общения не победить.

### Игровой цикл

1. **Подготовка (60 сек):** игроки расставляют ловушки на бюджет.
2. **Ночь (5 мин):** воры приходят волнами.
3. **Итог:** сколько украдено, сколько поймано, сколько заработано.
4. **Магазин:** улучшения (новые камеры, ловушки, залы).

### Роли

- **Оператор** — сидит в диспетчерской, переключает камеры, видит воров. Не может выйти в залы.
- **Патруль** — бегает по залам, ловит воров касанием.
- (позже) **Техник** — ставит и чинит ловушки, управляет светом.
- (позже) **Хранитель** — прячет ценные экспонаты в сейф.

## ТЕКУЩИЙ ЭТАП: прототип

Цель прототипа — проверить, весело ли играть. Делаем **только** это:

- [ ] Лобби → старт ночи, когда все игроки нажали «Готов»
- [ ] Выбор роли: Оператор / Патруль (если 1 игрок — только Патруль, камеры на клавише)
- [ ] Один зал, диспетчерская, 3 экспоната
- [ ] Камеры: 3–4 точки, оператор переключает их кнопками или цифрами 1–4
- [ ] Один тип вора — **Карманник**: появляется у входа → идёт к случайному экспонату → хватает (3 сек) → бежит к выходу. Пойман касанием патруля.
- [ ] Одна ловушка — **Лазерная сетка**: вор, пересёкший её, замедляется на 5 сек и подсвечивается.
- [ ] Таймер ночи, подсчёт украденного и пойманного, экран итога
- [ ] Деньги за ночь (без магазина пока)

Не добавляй ничего сверх списка без запроса владельца.

## Структура кода

Синхронизация со Studio через **Rojo** (или Script Sync, если владелец так решит).

```
src/
  server/
    GameLoop.server.luau      — фазы: Lobby → Prep → Night → Results
    RoleService.luau          — выдача ролей
    ThiefService.luau         — спавн и поведение воров
    TrapService.luau          — ловушки
    ScoreService.luau         — счёт, деньги
    DataService.luau          — сохранения (DataStore), позже
  client/
    CameraController.client.luau — вид оператора
    UI/                       — интерфейс
  shared/
    Config.luau               — все числа (время, скорость, цены) в одном месте
    Remotes.luau              — список всех RemoteEvent / RemoteFunction
```

## Обязательные правила кода

1. **Сервер решает всё важное:** поимка, кража, деньги, роли. Клиент только показывает и шлёт намерения. Никогда не доверяй клиенту числа.
2. **Все числа — в `shared/Config.luau`**, не внутри логики.
3. **Все Remote — в `shared/Remotes.luau`**, с проверкой аргументов на сервере.
4. **Отключай события** (`:Disconnect()`), когда объект уничтожен, — без утечек памяти.
5. **DataStore** — всегда через `pcall`, с повторной попыткой. Тестировать сохранения отдельно.
6. Код на Luau, с типами там, где это несложно.
7. Одна задача — один коммит.

## Модели из `assets/`

Друг кладёт FBX в `assets/models/` по шаблону имени:
`hall_*.fbx`, `exhibit_*.fbx`, `trap_*.fbx`, `thief_*.fbx`, `camera_*.fbx`, `prop_*.fbx`.

Импорт в Studio делает владелец (через Import 3D). В коде ищи модели по именам в `ReplicatedStorage/Models/`. Пока модели не готовы — используй простые блоки-заглушки с теми же именами, чтобы потом просто заменить.
